# WakeBee — previous release channel

WakeBee 0.15.1 and later are available in [WakeBee-Releases](https://github.com/jswladitya/WakeBee-Releases/releases/latest).

**Upgrading from 0.14 or earlier requires a one-time manual installation.** Keep the lid open, end the session, remove closed-lid setup in the old app, disable its Launch at login, and quit before replacing it.

[Read the full migration instructions and download](https://github.com/jswladitya/WakeBee-Releases/releases/tag/v0.15.1).

Earlier release files remain here for migration and recovery. The signed update feed points existing users to the manual upgrade instructions; it does not automatically install a different bundle identity.
