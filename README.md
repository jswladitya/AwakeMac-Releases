# WakeBee

Keep your Mac awake for as long as you need, right from the menu bar.

[Download for Mac](https://github.com/jswladitya/AwakeMac-Releases/releases/download/v0.14.0/WakeBee-0.14.0.dmg) · [Release notes](https://github.com/jswladitya/AwakeMac-Releases/releases/latest)

## Install

Open the DMG, drag **WakeBee.app** onto **Applications**, then open it from Applications. Activate using the key from your Polar purchase. Existing Polar licenses remain compatible with the WakeBee rename. End any active session and quit an older copy before replacing it manually.

## Features

- **Timer, Until, and Unlimited** keep-awake sessions.
- Optional **closed-lid mode**, with confirmation when ready.
- Configurable power-adapter requirements and battery limits.
- Native macOS interface with Liquid Glass on supported macOS versions.
- Signed updates through Sparkle, installed when you choose.
- Visible closed-lid setup errors and a **Copy setup details** button.

Requires **macOS 14 or later** and a valid Polar license for this app. Includes **Apple silicon and Intel** builds. The app and DMG are Developer ID signed, notarized by Apple, and stapled.

For closed-lid mode, complete setup and any macOS background-service approval. Keep the lid open until WakeBee confirms **Ready to close the lid**. A power adapter is required by default; battery use is opt-in. Closed-lid behavior has not been verified on every Mac model or macOS version; test it on your Mac before relying on unattended work.
