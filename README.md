# AwakeMac

A native macOS menu-bar app for manual keep-awake sessions, with optional closed-lid protection.

## Test release: 0.12.1

[Download AwakeMac for Mac](https://github.com/jswladitya/AwakeMac-Releases/releases/download/v0.12.1/AwakeMac-0.12.1.dmg) · [Installation and testing instructions](https://github.com/jswladitya/AwakeMac-Releases/releases/tag/v0.12.1)

- macOS 14 or later; Apple silicon and Intel.
- App and installer are Developer ID signed, notarized by Apple, and stapled.
- Open the DMG, drag AwakeMac onto Applications, then open it from Applications.
- A valid AwakeMac license key is required.
- Future updates are delivered through Sparkle.

This is a development preview for testing. Keep the lid open until the app explicitly confirms **Active — You can close the lid**. See the release notes for the testing flow and feedback details.

[ZIP download](https://github.com/jswladitya/AwakeMac-Releases/releases/download/v0.12.1/AwakeMac-0.12.1.zip) is also available. Sparkle updates continue to use the signed ZIP.
